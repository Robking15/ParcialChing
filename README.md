# ParcialChing

https://portaldocenteusb.netlify.app

Portal web de gestión académica para docentes de la Universidad de San Buenaventura Cartagena.

Permite a los profesores registrarse, iniciar sesión y consultar su horario, clases asignadas, aulas y perfil personal.

Incluye panel principal con resumen de actividad, próxima clase y navegación sencilla entre secciones.

Desarrollado como prototipo con HTML5, CSS3 (Flexbox/Grid y responsive) y JavaScript (validaciones, modales y localStorage).

Diseño adaptado a la identidad visual de la universidad con logos e imágenes reales del campus.
